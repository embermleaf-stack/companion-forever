## Summary

- **Overall risk rating: MEDIUM** (agent judgement, not a legal conclusion). Much lower than "Forever Companion" (HIGH), but not low.
- **Finding 1. No Blizzard mark and no Blizzard-product echo.** Neither "Hawthorn" nor "Journal" appears on Blizzard's published Trademark Usage Guidelines list, and the name contains no "WoW", "Warcraft", "Blizzard", "Battle.net" or "Forever". The literal API Terms §2(m) title rule is not touched as far as the published list shows. Implied affiliation is low. One caution: the WoW API and UI use "Journal" for the Encounter Journal / Adventure Guide (section 1.3), so marketing copy should not say "Encounter Journal" or "Adventure Guide".
- **Finding 2. The exact phrase "Hawthorn Journal" was not found** as an app, game, repository or brand in any search run (Play/App Store via web search, GitHub, itch.io, general web). Exact-match domains `.com`, `.app`, `.dev`, `.org`, `.net` had no DNS delegation (a signal that they may be unregistered, not proof).
- **Finding 3 (main risk). "HAWTHORN" is claimed for game software in Class 9 by Near Studios Inc.** A UK Trade Mark Journal entry (No. 2025/043, 24 Oct 2025) lists an international registration **HAWTHORN**, WO0000001879894, owner Near Studios Inc., covering Class 9 downloadable computer and video game software including for mobile phones (seen via search-result text; the page refused a direct fetch, so the wording is **UNVERIFIED**). Near Studios (NEARstudios) is developing *Hawthorn*, a cozy fantasy sandbox RPG on Steam (release "To be announced"). A cozy, hawthorn-themed game app called "Hawthorn Journal" could be read as a companion or journal for that game. Same class, overlapping audience (fantasy/RPG players), dominant word identical.
- **Recommendation:** "Hawthorn Journal" is usable as a working public name **only after** the owner's own registry checks (section 4) confirm the scope and status of the Near Studios HAWTHORN filings in the US, EU and UK, and ideally after a professional knock-out opinion. If those checks show HAWTHORN registered or pending for Class 9 mobile game software in the launch markets, treat the risk as HIGH and use a fallback (section 6).

## 1. Blizzard Entertainment

### 1.1 API Terms §2(m) and §4

Source: Blizzard Developer API Terms of Use, https://www.blizzard.com/en-us/legal/a2989b50-5f16-43b1-abec-2ae17cc09dd6/blizzard-developer-api-terms-of-use (last updated 1 Oct 2019; text as quoted in the Forever Companion review, read 2026-11-08).

- §2(m): "Your Application shall not contain any of Blizzard's trademarks as a part of its title or URL", and the app must name Blizzard as data source "in such a way which makes it not appear that Blizzard is endorsing or affiliated with Your Application."
- §4: no public statements that "assert or imply any other relationship with Blizzard".

"Hawthorn Journal" contains no Blizzard mark from the published list (1.2). It has no word associated with a Blizzard product title. **Agent view: not touched.** This is a reading of the published list, not a finding that Blizzard holds no other marks (UNVERIFIED).

### 1.3 "Journal" inside WoW

- The WoW Game Data API exposes `/data/wow/journal-expansion/…`, `/data/wow/journal-instance/…` and `/data/wow/journal-encounter/…` (Blizzard API forum announcement "World of Warcraft API Update - Visions of N'zoth", https://us.forums.blizzard.com/en/blizzard/t/world-of-warcraft-api-update-visions-of-nzoth/3461, posted 12 Feb 2020 by "Araspir"; staff status not labelled on the page, UNVERIFIED). The in-game UI is the "Adventure Guide", historically "Encounter Journal" / "Dungeon Journal" (secondary: warcraft.wiki.gg API pages, search snippets only).
- The WoW: Forever Collector's Edition includes a physical "companion journal" (Blizzard News, read for the earlier review).
- What this means: "Journal" is a common descriptive word, also used by Blizzard as a feature name, not as a listed mark. "Hawthorn Journal" does not copy "Encounter Journal" or "Adventure Guide". **Do not** describe the app as an "Encounter Journal", "Adventure Guide" or "companion journal" in the store listing, and do not use "Collector's Edition" style wording. Risk: **Low**.

### 2.3 "Journal" crowding

- Apple ships its own "Journal" app (iOS 17.2, December 2023; Wikipedia "Journal (Apple)", App Store id6447391597, secondary). Many third-party apps use "Journal"/"Diary" in titles (Day One, Journey, Diarium, Hindsight, Memoir & Journal; search results 2026-11-08).
- "Journal" is descriptive or generic for journaling software. It adds little distinctiveness; the brand weight falls on "Hawthorn". That makes the Near Studios HAWTHORN mark more relevant, not less.
- Store fit: the app is a character and activity checklist, not a diary. "Journal" fits the adventurer's-journal look (STYLE-GUIDE.md) but users searching "journal" may expect a diary. Use a clear subtitle/short description ("activity checklist for game characters" style wording, owner to approve). Do not imitate Apple Journal's icon or name styling (Apple 4.1).
- Risk: **Low** for conflict with any single "Journal" brand; **Low-Medium** for user expectation/metadata accuracy.

## 3. Platform rules

Same sources as the earlier review (section 3), read 2026-11-08.

- Google Play Metadata (https://support.google.com/googleplay/android-developer/answer/9898842): title "30 characters or less", no promotional text or misleading metadata. "Hawthorn Journal" = **16 characters**. With a descriptor, e.g. "Hawthorn Journal: Checklist" = 27, fits.
- Google Play Impersonation (answer/9888374) and Intellectual Property (answer/9888072): the name implies no relationship with Blizzard. The residual issue is similarity to *Hawthorn* (Near Studios): "App titles and icons that are so similar to those of existing products or services that users may be misled" (Impersonation policy). Keep the icon and art clearly distinct from *Hawthorn*'s key art.
- Apple App Store Review Guidelines (https://developer.apple.com/app-store/review/guidelines/) 2.3.7 (unique name, 30 characters, no trademarked terms in metadata), 4.1(c) (no other developer's brand or product name in the app name without approval), 5.2.1. Same residual issue as above.
- Fit: **Low** risk, provided the Near Studios checks come back clear.
