# Sponsorship and Blizzard API compliance

**Status:** HOLD — 2026-11-07. No active funding link has been authorized.

## Purpose

Prepare optional, unconditional support for original open-source development while avoiding monetization of Blizzard APIs, game data, or player access. The project is independent and not endorsed by Blizzard Entertainment.

## Sources and risk

- Blizzard Developer API Terms: https://www.blizzard.com/en-us/legal/a2989b50-5f16-43b1-abec-2ae17cc09dd6/blizzard-developer-api-terms-of-use
  - Section 2(b) bars premium API features, paid access, and interstitial donation requests before functionality.
  - Section 2(h) bars use of the APIs or Data for marketing or monetization purposes. It is not established whether unconditional GitHub Sponsors support for a project using Blizzard APIs is permissible.
- GitHub Sponsors personal enrollment: https://docs.github.com/en/sponsors/receiving-sponsorships-through-github-sponsors/setting-up-github-sponsors-for-your-personal-account
- GitHub FUNDING.yml syntax: https://docs.github.com/en/repositories/managing-your-repositorys-settings-and-features/customizing-your-repository/displaying-a-sponsor-button-in-your-repository

## Required gates before enabling a Sponsor button

1. Enroll the personal GitHub account `embermleaf-stack` in GitHub Sponsors, complete 2FA, identity, bank/Stripe, tax, profile, and GitHub approval. Do not commit personal financial or tax information.
2. Obtain written Blizzard clarification or qualified legal advice specifically addressing optional GitHub Sponsors support on a public repository for an API-connected, free companion app. Record date, source, conditions, and exact scope.
3. Confirm all tiers have no premium app features, private API-derived data, early access to API functionality, advertisements, or preferential functionality.
4. Confirm sponsor language is independent-project support only, without Blizzard trademarks in sponsor tier branding or endorsement implications.
5. After approval, uncomment `github: embermleaf-stack` in `.github/FUNDING.yml` and verify the GitHub repository Sponsorships feature displays the correct account.
6. Recheck Blizzard and GitHub terms periodically and on material product changes.
