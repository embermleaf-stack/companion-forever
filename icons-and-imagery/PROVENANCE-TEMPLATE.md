# Provenance entry template

Copy one block per delivered asset into `icons-and-imagery/provenance.md`.

```markdown
## <asset file name>

- **Date generated:** YYYY-MM-DD
- **Created by:** human illustrator | AI tool (name, version/model)
- **Prompt (verbatim) / brief used:**
- **Reference images used:** none  (any reference must be original/owned; state source)
- **Tool/output license terms:** <URL + date checked + operative clause permitting GPL-3.0 open-source redistribution>
- **Human edits:** <what was edited by hand, by whom>
- **Similarity check:** <how it was checked against existing game art/logos; reviewer name>
- **Alt text:**
- **Reviewed by / approved by owner (date):**
```

An asset without a completed entry must not be merged.
